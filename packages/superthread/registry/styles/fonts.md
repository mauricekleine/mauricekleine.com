# superthread fonts

Self-host Panchang 600 and 800 for display, Supreme 400 and 500 for body,
and Fragment Mono 400 for labels. Set `font-display: swap` on each face.
The font stacks and type scale come from `tokens.css`.

Import `superthread.css` once after Tailwind's theme and utilities.
Use `data-mode="paper"` on an ancestor for paper mode.
