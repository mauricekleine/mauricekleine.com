# data display

## zero, missing and comparisons (F14)

show a real zero as zero and a missing value as missing. when a comparison starts
from zero, use a count or plain explanation instead of a percentage growth badge.
neutral or undefined change uses the existing neutral treatment, without implying
success or failure.

## chart legends (F15)

derive chart marks and their legend swatches from the same style definition. the
swatch repeats the plotted mark's color, pattern and outline; include only series
present in the view.
