# mauricekleine.com

This is Maurice's public identity monorepo. `apps/web/` is the live TanStack Start app. `apps/site/` remains an unchanged parity reference until a later cleanup. `packages/` is reserved for the superthread design system and shared config presets. `skills/` is reserved for public brand skills.

Read `apps/web/CLAUDE.md`, `apps/site/PRODUCT.md`, and `apps/site/DESIGN.md` before site work. The existing visual design and copy are the port's parity baseline.

Run commands from the repo root. `bun run dev` starts the web app on port 3000, `bun run build` prerenders every page and prepares Wrangler's root deploy config, `bun run test` checks the Worker, and `bun run deploy` deploys through the generated config. Cloudflare Workers Builds runs from this root.

Keep Maurice's voice lowercase and understated. No em dashes in new copy.
